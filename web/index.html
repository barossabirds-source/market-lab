How to read this: the tariff table uses the same high-surprise escalation rule each time and subtracts the all-in cost entered above from every historical example. The running sum is not a portfolio backtest: events can overlap, and tax, slippage, financing, short-borrow costs and differences in execution timing are not fully modelled. A weaker result in later periods can suggest a changing market response, but it does not prove that repeated announcements caused the change.

When a strategy is ready for simulation

State the rule before testing it.

Use historical or later data that was not used to choose or judge the rule.

Record what the fixed rule would do on genuinely new data.
